# PATCH 5 — 사전·온라인목록 외부 엑셀 분리

> 목표: 회계사가 코드 수정 없이 금융기관 사전과 온라인 조회목록을
> 엑셀로 갱신할 수 있게 한다. (7장 열린 결정 → "지금" 외부화)

## 변경 내역

| 파일 | 작업 | 비고 |
|---|---|---|
| `fi_detector.py` | 확장 | 외부 엑셀 로더 + `reload_external` + `export_templates` + 임포트 시 자동 반영 |
| `pages/13_Confirmation_Population.py` | 수정 | 사이드바에 출처 표시 + "엑셀 템플릿 내보내기" 버튼 |
| `test_external_dict.py` | 신규 | PATCH 5 회귀 테스트 |

## 동작

- 앱 폴더(`fi_detector.py` 옆)에 아래 파일이 있으면 내장 기본값 대신 사용:
  - `금융기관사전.xlsx` — 열: 카테고리, 키워드
  - `온라인조회목록.xlsx` — 열: 기관명, 유형, 서비스일자, 전화번호
- 파일이 없거나 읽기 실패 시 **내장 기본값으로 자동 복귀**(동작 불변).
- 임포트 시 `reload_external()` 자동 호출. 외부 파일 없으면 기존과 100% 동일.
- 사이드바 "현재 사전 → 엑셀 템플릿 내보내기": 현재 사전을 위 두 파일로 생성
  → 회계사가 엑셀에서 추가/삭제 후 새로고침하면 반영.
- 외부 통신 없음. 로컬 엑셀만 읽는다.

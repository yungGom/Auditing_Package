## 증분 ① 제3 모듈: XBRL Studio (비활성 슬롯 → 정식 모듈 승격)

좌측 네비를 3모듈로 재편:
```
🗂 DSD Workbench   (기존 그대로)
📐 XBRL Studio     (신규 — v1의 "트리 뷰/차원 표/매핑" 비활성 탭이 이 모듈로 승격)
🔍 DART Explorer   (기존 그대로 — 검색·수집·파이프라인 실행만 남김)
```
XBRL Studio 헤더 뱃지: `🔒 분석·작성은 로컬 — 코퍼스는 공개데이터`

### 화면 구성 (5개)
1. **택사노미 체크** (시즌 착수 화면) — 전기 인스턴스 대조 결과:
   상단 요약(그대로 사용 N · 폐지 M · 라벨변경 K), 폐지 항목마다 **추천 카드**(증분②)로
   대체 후보 제시. "착수 전 체크리스트 엑셀 내보내기" 버튼
2. **매핑 확정** — 계정과목 리스트(좌) + 선택 항목의 추천 카드 스택(우).
   진행률 링(확정 n/전체 N), 필터(미확정/확장필요/전체)
3. **작성 워크시트** (Phase F) — 시트 탭(BS/PL/../1..N), 각 행: 계정 | 값 |
   element | 편집기 검색어(복사 버튼 📋 — 전사 동선의 핵심) | 확신도 | 확정☐.
   상단: "작성 개요" 요약(미매핑 j건 · 확장 후보 k건 · 확정률 %)
3. **차원 표 뷰어** — D-2 렌더 결과 웹 표시 (기간 블록: 당기 3개월/누적…,
   중첩 헤더, 음수 빨간 괄호). 시트 선택 = BS/PL/../1,2,3 체계
5. **트리 뷰** — Role 선택 → 들여쓰기 트리, 확장 element 빨간 표시

## 증분 ② 공통 컴포넌트: "추천 카드" ★ 이 제품의 아이덴티티

전 모듈에서 재사용되는 단일 컴포넌트로 정의할 것 (컴포넌트 스펙 필수 산출):
```
┌─────────────────────────────────────────────┐
│ ifrs-full:CashAndCashEquivalents            │ ← 후보 1순위 (ID + 표준 한글라벨)
│ 현금및현금성자산                               │
│ [실증 2,714사] [유사도 1.00] [동업종 ×2]       │ ← 근거 뱃지 (실측 문자열 기준)
│ ▸ 대안 3건 보기                               │ ← 2~4위 접기
│                        [확정]  확정: 문용 7/12 │ ← 확정 버튼 + 기록
└─────────────────────────────────────────────┘
상태 변형 4종:
  기본(추천) / 확정됨(체크·잠금) / [확장 필요](표준 임계 미달 — 유사 확장 실증 병기)
  / [표준 사용 권장](확장 정의하려는데 고유사 표준 존재 — amber 강조)
```
사용처: 매핑 확정 · 택사노미 체크 대체 후보 · F 워크시트 행 확장 · Footing 레벨 제안.
근거 뱃지의 숫자는 실데이터 규모(코퍼스 3,976사, Top-4 적중 99.0%)를 전제로 —
"실증 N사"가 세 자릿수인 게 일상적임을 감안한 시각 밀도로.

## 증분 ③ 홈: 시즌 여정형 재구성

작업 목록 위에 "지금 할 일" 레이어:
```
[시즌 착수]  택사노미 체크 → 작성 워크시트 → 편집기 전사
[결산]      DSD 추출 → 엑셀 편집 → Footing → 변경검토 → repack → DART 확인
[수시]      벤치마크 검색 · 차원표 조회 · 코퍼스 갱신
```
- 각 여정 카드: 다음 단계 하이라이트 + 해당 화면 바로가기
- 우측: 상태 요약 카드 (E-0 대시보드 축약 — 코퍼스 최신성, 게이트 현황, 편집기 버전)
- 최근 세션 목록은 그 아래 유지 (v1 그대로)

## 증분 ④ A-5 반영 (DSD Workbench 내)

1. Footing 탭 상단에 버튼: **"AI_Footing 엑셀 내보내기"** (총괄표 형식 독립 파일)
2. Footing 탭에 서브탭 추가: **전기대사**
   - 상단 판정 배너: 전체 **TRUE / FALSE** (FALSE면 red, 건수 병기)
   - 안내 1줄: "FALSE 존재 시 전기 재작성·계정 재분류 여부를 확인하십시오"
   - 테이블: 계정과목 | 당기보고서 전기값 | 전기보고서 당기값 | 판정(TRUE/FALSE 칩) | 비고
   - 전기 소스 표시: 로컬 DSD / OpenDART 수신(캐시) 구분 뱃지
   - "전기대사 엑셀 내보내기" 버튼

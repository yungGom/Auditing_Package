# [패치 V-1] DSD ↔ XBRL 인스턴스(IXD) 대사 — 인벡터 기능 ② 대응

> 목적: 같은 회사의 DSD 값 ↔ XBRL 인스턴스 팩트 값 자동 대조
> (태깅이 공시 본문과 일치하는지 — 제출 직전 최종 검증)
> 조립 패치: B-3 수신 인스턴스 · XbrlInstance 파서 · F-1/F-3 매핑 ·
> A-5 엑셀 규격 · 전기대사 판정 규격 재사용. 신규 코드 최소화.

## 1. 입력

- **DSD**: Workbench 세션의 현재 DSD — 편집기 왕복 계열(dartdb 포함) 기준.
  OpenDART 래핑 수신물(meta.xml 없음 → editver 미검출로 판별)이 입력되면
  **"주석 분할 부정확 — 참고용" 경고** (UI-5 주의사항 준용, B-2 구조대조 §2).
- **XBRL 패키지**: explorer 캐시 경로 (recon 모드②와 동일 경계 —
  dsd_workbench는 파일 읽기만).
- **경계**: 수신·인스턴스 파싱(XbrlInstance)은 라우터(studio 조립층)에서
  수행해 팩트 dict로 전달, **대사 로직은 dsd_tool.xbrl_recon** (workbench
  함수). import 방향 불변. LLM API 불사용, 송신 코드 금지.

## 2. 매칭 — DSD 계정 행 ↔ 인스턴스 팩트 (스코프: 본문 FS)

- **element 매핑 (신규 추론·강제 매칭 금지)**:
  1. F-1 확정 기록 — Studio 매핑 확정(mapping_decisions)의
     `계정명(정규화) → element` (누가/언제 기록된 것만)
  2. F-3 승계 — 대상 인스턴스의 succession_assets.json
     (정확 일치 + 기말 풀 한정 유사도 폴백, F-3 로직 그대로)
  3. 둘 다 없으면 **매핑 없음** (판정 불가 — 별도 집계, 태깅 누락과 불혼합)
- **컨텍스트 선별**: 당기 보고기간 자동 —
  instant = 인스턴스 doc_period_end 시점, duration = end가 doc_period_end인
  기간 중 최장(연간 누적). 연결/별도는 DSD 문서(시트명 접두)를 따름 —
  ConsolidatedAndSeparate 축 member 일치 또는 무차원 문맥만 허용,
  **그 외 축이 붙은 문맥은 배제** (D-2c 오매칭 교훈: 섹션 외 축 유입 차단).
- **단위 정규화**: DSD 표시단위 행("(단위: 백만원)" 등) 자동 탐지 →
  원 단위 환산 후 대조 (원=1 / 천원=1e3 / 백만원=1e6 / 십억=1e9).
- **허용오차**: 인스턴스 decimals 속성 기반 자동 산정 —
  `tol = 0.5 × 10^(-decimals)` (decimals<0), DSD 표시단위 반올림 반영
  `+ 0.5 × scale`. 수동 오버라이드(`tolerance`) 지정 시 그 값 사용.

## 3. 판정 — 전기대사와 동일 규격 (TRUE/FALSE + 비고), 5분류

| 분류 | 조건 | TRUE/FALSE |
|------|------|-----------|
| 일치 | \|DSD값(원) − 팩트값\| ≤ 허용오차 | TRUE |
| 값 상이 | 매핑·팩트 모두 존재, 차이 > 허용오차 | FALSE |
| 태깅 누락 | 매핑은 있는데 당기 문맥 팩트 없음 | FALSE |
| 인스턴스에만 있음 | 당기 순수 문맥 팩트의 element가 DSD 행에 미대응 | FALSE(참고) |
| 매핑 없음 | F-1 확정·F-3 승계 모두 부재 — 판정 불가 | 별도 집계 |

※ **미매칭 ≠ 0**: 매핑 없음을 태깅 누락에 섞지 않고 그대로 노출.

## 4. 출력 — 대사표 엑셀 (A-5 규격)

- 요약 시트: 대조율(매칭/전체) · 판정 분포 5분류 · 허용오차 사용값
  (자동/수동) · 시트 하이퍼링크 · FALSE 존재 시 안내 1줄
- 시트별 상세: DSD 행 | DSD값(표시단위) | 원환산 | element | 팩트값 |
  차이 | 판정 | 비고 — FALSE 행 하이라이트(A-5 빨강), 헤더 회색,
  숫자 #,##0;(#,##0)
- '인스턴스에만 있음' / '매핑 없음' 별도 목록 시트

## 5. UI

Workbench 세션 Footing 탭 **"XBRL 대사" 서브탭** (전기대사 옆) —
패키지 경로(최근 수신 드롭다운) → 실행(job) → 판정 배너 + 분포 칩 +
결과 테이블(FALSE만 필터) + 엑셀 다운로드.

## 게이트

- G1 신원종합개발 왕복 — DSD·인스턴스 모두 보유 건 실행,
  본문 대조율 리포트 (매칭률·판정 분포)
- G2 변조 테스트 — 인스턴스 팩트 1개 값 수정 후 재실행 →
  해당 행만 FALSE(값 상이) 전환, 나머지 판정 불변
- G3 산출 엑셀 A-5 규격 준수 스크린샷

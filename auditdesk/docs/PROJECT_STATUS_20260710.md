## 2. 완료된 패치 상세

### Phase 0. DSD ↔ Excel 파이프라인 (프로젝트 원점)

| 항목 | 내용 |
|------|------|
| 문제 | DART 편집기 직접 편집의 비효율 → 엑셀 편집 후 DSD 역변환 필요. 초기 "찾아치환" 방식은 동일 숫자 오교체·빈셀 불가로 실패 |
| 해결 | **위치 기반(문자 오프셋) 교체** — 추출 시 셀별 XML 좌표를 _MAP에 기록, 역변환 시 변경분만 역순 교체 |
| 근거 데이터 | 실공시 DSD 10사 배치 분석 (삼성전자 별도/연결, LG화학, 에코프로비엠, 삼천당제약, KB금융, 삼성화재, 노무라, 홈플러스, 티에스넥스젠) → 구조 불변식 확정 |
| 핵심 발견 | 주석 헤더 = `SPAN USERMARK=" B"` (10/10) / FS 제목 = TD 테이블(TITLE 아님) / 공시 DSD엔 감사보고서 본문 없음(placeholder) / LF-only 직렬화 / dartdb 주석번호 오염("N. N.") |
| ACCIO 역분석 | 시트 체계 BS/PL/PL1/CE/CF/1..N 채택. ACCIO 한계(숫자가 문자열, 검증 불가 블랙박스, 클라우드 필수) = 우리 차별점 |
| 게이트 | G1(10사 전수 추출) ~ G5(빈셀 삽입) 실파일 통과, **DART 편집기 열림 실증** (6_0변환 파일) |
| 부가 기능 | `--clean-cr`(빈셀 &cr; 정리 — "한 칸 두 줄" 해결, 기본 동작) / 주석번호 중복 정리(기본 동작) / 엑셀 테두리 / 혼합 셀(두줄 헤더) 보존 |
| 검증 자산 | 한빛정밀 합성 데이터셋(대사 완결 가상회사) — "실DSD 뼈대+값교체"로 생성, DART 열림 확인. from-scratch 생성은 스키마 검증 실패로 폐기(원칙 재확인) |

### Phase A. 아키텍처 재편 (dsd_workbench)

| 패치 | 내용 | 게이트 |
|------|------|--------|
| A-1 | 2-앱 분리: `dsd_workbench/`(완전 오프라인, 네트워크 라이브러리 의존 금지) + `dart_explorer/`(OpenDART 수신 전용). 보안 원칙 정밀화: 공개데이터 **수신 허용** / 고객데이터 **송신 금지** | 전체 테스트 + batch_validate 10/10 |
| A-2 | 수정이력 SQLite — repack마다 변경 셀·사유(edit/clean-cr/note-dedup)·SHA1 기록. 감사조서 증빙용 | 이력 조회·dry-run 미기록 |
| A-3 | 편집기 버전 관리 — editver 감지, KNOWN_VERSIONS.md, 미확인 버전 경고 | 10사 editver 추출·가짜버전 경고 |
| A-4 | **Footing 검증** — DSDbreaker(실무 VBA 1,480줄) 역분석 이식: 값 기반 계층 역추론(키워드 불사용, ±2 단수차), **양방향 스캔으로 확장**(한국 FS 상단 소계 대응), 합계검증+주석대사(참조텍스트 결합)+전기대사, 레벨 수동 오버라이드 | G-F1~F4: 한빛 관계 45개 전부 일치, 변조 검출, 삼성전자 실파일 BS 14·PL 6 관계 불일치 0 |

## 4. 투입 대기 (지시서 전달 완료)

- **A-3b** version-check 명령 — 독립 소품, E-0 이후 아무 때나
- **D-4** 택사노미 버전 관리 — **D-3b 게이트 통과 후** (D-4c/d가 매핑 엔진 의존)
  - 실파일 2세대 확보: 2024-06-30판·2026-01-31판 → `taxonomies/` 배치 필요 (문용님)
  - 게이트 기대값 사전 실측: **신설 1,334 / 폐지 156 / 유지 7,652** (열 배치 세대별 상이 — 헤더 탐지 필수)
  - 구성: D-4a 버전 저장소 / D-4b diff / D-4c 착수 전 체크리스트(폐지→대체 후보 자동) / D-4d 확장→표준 승격 감지
- **DART 편집기 버전 절차** — 신버전 출시 시: 편집기로 뼈대 변환 → G2 재검증 → KNOWN_VERSIONS 갱신 (도구는 버전 창작 금지)

## 6. 핵심 기술 결정 아카이브 (재확인용)

1. DSD는 창작 불가 — 유효 DSD 뼈대 + 값 교체만 (스키마 검증)
2. 위치 기반 교체가 유일하게 신뢰 가능 (찾아치환 폐기)
3. 버전 정보(editver/택사노미)는 공식 도구가 변환, 우리는 감지·대조·리포트만
4. 자동은 후보 추천·확정은 회계사 (Footing 레벨 오버라이드, 매핑 Top 4, 승격 감지 전부 동일 패턴)
5. LLM API 불사용 — 실증 빈도+규칙 스코어로 대체 (보안·재현성·조서 근거)
6. 신뢰 경계 분리 — workbench(오프라인)/explorer(수신) 코드 격리, 연결은 파일로만

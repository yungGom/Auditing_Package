# [패치 F-3b] 롤포워드 세팅 — 전기 반기 DSD × 기말 인스턴스 → 당기 워크시트

> 발원: 종합_작업계획_2026반기시즌.md 부록 A (2026-07-20 접수).
> 목적: 반기 실전 건의 스캐폴드 — 전기(2025) 반기 DSD의 범위 위에
> 기말 인스턴스 태깅을 승계하고 전기 비교값을 프리필해, 당기값만 채우면
> 되는 전사 가이드를 만든다.
> 게이트는 **공시된 전기(2025) 자료만** 사용 — 미공시 당기 수치 파일은
> 세션 반입 금지 (실작업은 사용자가 로컬 실행).

## 1. 입력 3종

| # | 입력 | 역할 | 비고 |
|---|---|---|---|
| ① | 전기 반기 DSD | 범위 템플릿 (시트·주석·표 구성) | 로컬 보유본 1순위. OpenDART 수신본은 경고 + 신뢰 범위 한정 (B-2 §2 — 주석 분할 부정확) |
| ② | 전기 기말 XBRL 인스턴스 | 태깅 출처 (F-3 승계 로직 그대로) + 전기말 시점 값 | succession_assets.json (F-3 산출) + 팩트 |
| ③ | 전기 기말 DSD | ②에 팩트 없는 주석 비교값 폴백 | A-5b 매칭 엔진 역방향 (제목·표·행 라벨 매칭) |

경계: 인스턴스 파싱·자산 준비는 조립층(호출자)이 수행해 팩트 dict로
전달 — 대사·조립 로직은 `dsd_tool.rollforward` (V-1과 동일 경계,
dart_explorer import 없음). LLM 불사용, 신규 매칭 코드 금지 —
승계는 `SuccessionAssets`, 컨텍스트 선별은 V-1 `_current_fact`,
주석 매칭은 A-5b `match_note_titles`/`_pair_regions` 재사용.

## 2. 동작

1. **범위**: ①의 본문(BS/PL/CE/CF)·주석 시트 구성 그대로 —
   반기에 없는 role은 애초에 ①에 없으므로 자동 제외.
2. **태깅**: F-3 승계 — ②의 element·확장·role. `inherit`(정확 일치 +
   기말 풀 유사 폴백)·`find_role`, D-4c 상태(`taxcheck_of`) 병기.
   D-2c 리졸버로 [한글 표준레이블][영문명][ID] 3열 충전.
3. **기간 롤포워드**: 전기 라벨 +1년 — `제 N 기` → `제 N+1 기`,
   연도 표기 +1 (당기 위치 헤더만. 비교 열은 전기 연도가 정답이므로
   유지). 헤더 재구성: BS = 당반기말(롤) / 전기말(=② 보고기간말),
   PL·CF = 당반기(롤) / 전반기(=①의 당기 라벨 그대로).
4. **전기값 프리필** — [값 출처] 열로 추적:
   - BS·주석 시점 값 = ② 팩트 직결 (element 키 + V-1 컨텍스트 선별
     재사용, instant end=기말) → `프리필-기말`
   - ② 팩트 없는 주석 값 = ③에서 A-5b 매칭 역방향 (제목 정규화 →
     표 자카드 페어링 → 행 라벨 매칭, ③ 표의 '당기' 열) →
     `프리필-기말(DSD)`
   - PL·CF·주석 흐름 값 = ①의 당기(제N기) 열 그대로 → `프리필-반기`
   - 미매칭 = 빈칸 + `수동 확인` (**미매칭≠0** — 숨기지 않는다)
5. **당기값 열 공란** — "(당기 확정 후 입력)" 표기.
6. **갱신 모드**: 당기 DSD 도착 시 재실행(`current_xlsx`) → ① 대비
   diff — 신규 계정만 D-3b 추천 부착(`recommend` 콜러블), 값 변경
   행 감지 표기, 기존 승계 정보 불변.

## 3. 산출 (스캐폴드 엑셀)

- 요약 시트: 프리필 충전율(출처별 분해) + 태깅 승계율 + 경고
  (수신본 신뢰 범위) + 게이트 수치
- 본문 시트: 행 라벨 | 당기값 공란(기간 열 수 유지) | 프리필 비교값 |
  [값 출처] | element ID | 한글 표준레이블 | 영문명 | 근거(승계/유사) |
  D-4c | 확정☐ — CE는 구조 복제+수동(자본 축 스코프 외, V-1과 동일)
- 주석 시트: ① 표 구성별 — 행 라벨 | 당기값 공란 | 전반기 프리필 |
  기말 프리필 | [값 출처] | element(승계 시) | 확정☐, 시트 상단 role 승계
- 미확정=미완성: 확정☐ 관례 (F-1과 동일)

## 4. 게이트 (신원종합개발 공시된 2025 자료, 보고 후 정지)

- G1 스캐폴드 생성 — 프리필 충전율 리포트 (출처별 분해)
- G2 프리필 표본 10건 ↔ 원천(공시 원문) 대조 일치
- G3 기간 라벨 전수 검사 — 당기 위치 라벨에 전기 연도·기수 잔존 0
- G4 갱신 모드 모의 — ① 사본에 계정 1개 추가·값 1개 변경한 가짜
  당기 DSD → 신규 1건만 추천 부착·변경 1건 감지·기존 승계 불변
- G5 전 테스트 회귀

※ 실전 클라이언트 재료(로컬 보유 반기 DSD 등) 확보 시 동일 함수로
재실행 — 게이트 산출과 실전 산출은 입력 경로만 다르다.

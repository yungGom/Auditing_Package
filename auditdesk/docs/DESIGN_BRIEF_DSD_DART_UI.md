# [Claude Design 브리프] AuditLink v2 — DSD Workbench & DART Explorer 모듈

> 용도: Claude Design에 전달할 화면 설계 브리프
> 스택: React + TypeScript + Tailwind (Vite), FastAPI + SQLite — AuditLink v2 표준
> 디자인 시스템: Material Design 3, primary navy #001e40, 폰트 Manrope/Inter (AuditLink v2 기존 토큰 준수)
> 스코프: 검증 완료된 백엔드 기능만 (dsd_tool extract/repack/foot/history, dart_explorer search/fetch/xbrl).
> Phase D(XBRL 트리·차원표·매핑)는 확장 슬롯만 남기고 이번 설계에서 제외.

---

## 0. 사용자와 사용 맥락

- 사용자: 회계법인 감사팀 (CPA와 스태프). 결산 시즌에 시간 압박 속 사용.
- 환경: 로컬 실행 웹앱 (localhost). 고객사 DSD 파일은 절대 외부로 나가지 않음.
- 톤: 도구적·밀도 높게. 마케팅 화면 아님. 숫자 가독성 최우선 (표 중심, 우측정렬, 고정폭 숫자).
- 참고 벤치마크: KPMG Footing Master의 findings 패널 (일치/단수차/불일치 뱃지 요약) — 이 밀도감.

## 1. 정보 구조 (좌측 네비게이션에 두 모듈 추가)

```
AuditLink v2
├── (기존) FY > Client > Phase > ...
├── 🗂 DSD Workbench        ← 신규 모듈 1 (오프라인 — 고객사 파일)
│   ├── 작업 목록 (최근 DSD 세션)
│   └── 세션 상세 (탭: 개요 | 시트 뷰 | Footing | 변경검토 | 이력)
└── 🔍 DART Explorer        ← 신규 모듈 2 (공개 데이터 수신)
    ├── 공시 검색
    └── XBRL 파이프라인
```

두 모듈은 시각적으로 구분되는 신뢰 뱃지 필요:
- Workbench 헤더에 상시 표시: `🔒 로컬 전용 — 외부 전송 없음`
- Explorer 헤더: `🌐 OpenDART 수신 전용`

## 2. DSD Workbench 화면들

### 2-1. 작업 목록
- DSD 파일 드래그&드롭 존 (크게) + 최근 세션 카드 목록
- 세션 카드: 파일명, 회사명(표지에서 추출), editver 뱃지, 마지막 작업일, 상태칩(추출됨/수정중/repack완료)
- 미확인 editver면 카드에 경고 뱃지 (⚠ 미검증 편집기 버전)

### 2-2. 세션 상세 — 탭 구조

**[탭1 개요]**
- 파일 메타: 원본 경로, SHA1, editver, 셀 수, 주석 수, &cr;-only 셀 수
- 파이프라인 스텝퍼: 추출 → 엑셀 편집(외부) → 변경검토 → repack → DART 확인
  현재 위치 하이라이트. "엑셀 열기" 버튼(OS로 위임), "편집 완료, 변경 검토" CTA
- 옵션 토글: &cr; 정리(기본 on), 주석번호 정리(기본 on) — off 시 사유 툴팁

**[탭2 시트 뷰]** (읽기 전용 미리보기)
- 좌측: 시트 트리 (표지/BS/PL/PL1/CE/CF/주석1..N/외부감사) — ACCIO식 약칭
- 우측: 선택 시트 테이블 렌더 (헤더 고정, 숫자 우측정렬, 음수 빨간 괄호)
- 편집은 여기서 하지 않음 — 엑셀이 편집기라는 워크플로우 유지 (명시 문구)

**[탭3 Footing]** ★ KPMG Footing Master 대응 화면
- 상단 요약 뱃지: ● 일치 N ● 단수차 M ● 불일치 K ● 주석대사 미매칭 J
- 좌측 findings 리스트 (필터: 전체/단수차/불일치/미매칭), 클릭 시 우측 해당 표로 점프
- 우측: 해당 시트 표 + 문제 셀 하이라이트 (단수차 노랑 / 불일치 빨강 + 차이액 배지)
- 각 합계 행에 추론 레벨 표시, 레벨 수동 수정 UI (드롭다운) → "재검증" 버튼
  (자동은 추천, 확정은 회계사 — 수정된 레벨은 뱃지로 구분)

**[탭4 변경검토]** ★ 이 모듈의 핵심 화면 (repack --dry-run 시각화)
- repack 전 승인 게이트. 테이블: 시트 | 셀 | 변경 전 | 변경 후 | 구분(수정/&cr;정리/번호정리)
- 구분별 그룹 접기, 건수 요약 ("수정 12 · &cr; 정리 319 · 번호 정리 32")
- 개별 변경 체크박스로 제외 가능 (기본 전체 선택)
- 하단 고정 CTA: [repack 실행] — 실행 후 출력 파일 경로 + "DART 편집기에서 확인" 체크리스트 모달
- 빈 상태: "변경 없음 — 원본과 동일합니다" (G2 상태)

**[탭5 이력]**
- history.sqlite 타임라인: 실행시각, 옵션, 변경 요약, 출력 SHA1
- 각 항목 펼치면 변경 셀 목록 (감사조서 증빙용 — "내보내기: 엑셀" 버튼)

### 2-3. 전기대사 모드 (Footing 탭 내 서브)
- "+ 전기 파일 연결" → 당기 전기열 ↔ 전기 당기열 비교 결과 리스트

## 3. DART Explorer 화면들

### 3-1. 공시 검색
- 검색 바: 회사명(자동완성 — corpCode 캐시), 기간 프리셋(당기/전기/직접), 업종코드, 보고서 유형 칩(사업/반기/분기/감사보고서)
- 결과 테이블: 회사 | 보고서명 | 접수일 | rcept_no | 액션(원본 다운로드 / XBRL 파이프라인 실행)
- 캐시 상태 표시: 이미 받은 항목은 ✓캐시 뱃지 (클릭 시 재다운로드 없이 열기)

### 3-2. XBRL 파이프라인
- 입력 카드: 회사 + 사업연도 + [버전대사: 전기 연도] 토글
- 실행 로그 스텝퍼: rcept 탐색 → 다운로드(또는 캐시) → 압축해제 → 팩트 추출 → 버전대사
- 결과 카드: 팩트 수, 대사 계정 수, 산출 엑셀 열기/폴더 열기 버튼
- 실패 상태 디자인: XBRL 미제출(안내형), API 키 없음(설정 유도), 한도 근접 경고
- (확장 슬롯) 결과 카드 하단에 비활성 탭 자리: "트리 뷰 | 차원 표 | 매핑" — Phase D 예정 표기

### 3-3. 설정 (Explorer 한정)
- API 키 상태 (.env 감지 — 키 값은 표시하지 않음, 설정 여부만), 캐시 용량/비우기, 일 사용량 카운터

## 4. 공통 컴포넌트 & 상태

- 숫자 셀: 고정폭 서체, 우측정렬, 음수 빨간 괄호 — 전 화면 일관
- 상태칩 팔레트: 일치(green)/단수차(amber)/불일치(red)/정보(navy)
- 파일 작업은 전부 비동기 + 진행 표시 (삼성화재급 2만 셀 = 수 초)
- 에러는 실무자 언어로: "엑셀이 열려 있어 저장할 수 없습니다 — 닫고 다시 시도" (PermissionError 번역)
- 빈 상태 일러스트 없음 — 텍스트 + 다음 행동 버튼만 (도구 톤 유지)

## 5. 명시적 비스코프

- 다중 사용자/권한, 클라우드 저장

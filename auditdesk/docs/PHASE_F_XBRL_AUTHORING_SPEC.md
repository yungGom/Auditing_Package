# [Phase F] XBRL 작성 워크시트 생성기 — DSD → 기공시 형식 엑셀

> 배경: XBRL 공시 대상 확대 — ①기말만 하던 회사의 분반기 첫 공시 ②완전 신규 공시.
>        분반기 주석 의무화: role 세트는 기말과 사실상 동일, 세부 레벨만 낮음 (문용님 확인).
> 목표: 회사 DSD 투입 → 동종업계·계정 유사성 분석 → 적절한 택사노미 반영 →
>        **기공시 XBRL에서 뽑은 것과 같은 형식의 엑셀** (본문+주석) 생성.
> 제약: 금감원 XBRL 편집기는 수작업 입력만 가능 (업로드 양식 없음) →
>        산출물 = "전사(轉寫) 가이드 워크시트". 입력자가 위에서 아래로 따라가며 편집기에 입력.
> 재사용 자산: dsd_tool extract(입력) + D-3b 매핑엔진(계정→element) +
>              코퍼스 dims(표→차원 실증) + D-2/D-2b 렌더러(출력 형식)

---

## 산출물 양식 (공통)

D-2b 차원표 형식(시트: BS/PL/PL1/CE/CF/1,2,3.., 계층 들여쓰기, role 코드 1행 보존)에 작성 지원 열 추가:

| 열 | 내용 |
|----|------|
| A~ | 계정/항목 (DSD 원문 라벨, 들여쓰기 계층) |
| 값 | DSD에서 추출한 금액 (기간 블록: 연간=당기/전기, 분반기=당기 3개월/누적/전기 3개월/누적) |
| element ID | 추천 1순위 (prefix:ElementName) |
| **편집기 검색어** | 표준 한글 라벨 — 편집기에서 element 찾을 때 그대로 입력할 검색어 |
| 확신도 | `실증 N사 · 유사도 0.xx` (동업종 가중 반영) |
| 대안 | 후보 2~4위 (접힘/주석 형태) |
| 확정 ☐ | 회계사 기입 — 미확정 상태로는 "완성" 아님을 시트 상단에 명시 |

- 확장 필요 판정 항목: element ID 자리에 `[확장 필요]` + 유사 확장 실증 사례 병기
- 시트 맨 앞 "작성 개요": role 구성 목록, 미매핑 잔여 건수, 확장 후보 건수 요약

## F-1. 본문 워크시트 (BS/PL/PL1/CE/CF) — 난이도 하

1. dsd_tool extract로 본문 계정·값·계층 추출
2. 계정별 D-3b Top 4 (동업종 ×2 가중) → 1순위 배치, 대안 병기
3. 기간 체계: 대상 보고서 유형(연간/반기/분기) 파라미터 → D-2b 기간 블록 규칙으로 값 배치
4. CE는 축 1개(자본구성요소) 표로 — 코퍼스 실증 member 매핑 (자본금→IssuedCapitalMember 등)

**게이트 F-1**: XBRL 기공시사(코퍼스 내) DSD 투입 → 생성 워크시트의 element를
해당사 실제 공시 인스턴스와 자동 대조. 본문 element 일치율 목표 90%+
(홀드아웃 방식 — 해당사를 코퍼스 집계에서 제외하고 추천)

## F-2. 주석 워크시트 — 핵심 난제 (표 → 차원 매핑)

1. **role 구성 제안**: DSD 주석 제목(1~N) ↔ 코퍼스 동업종 role 사용 실태 매칭
   → "이 주석은 [D822100] 유형자산 role" 배정 (미매칭 주석은 목록화 — 회계사 판단)
2. **표 → 차원 매핑** (2차원 문제):
   - 행 라벨 → member 또는 element (코퍼스 usages의 dims 실증 조회:
     "동업종에서 '토지' 행 라벨은 LandMember로 태깅" — D-3b 스코어러 재사용)
   - 열 라벨 → element 또는 기간 (기초/취득/처분/상각/기말 → 증감 element 패턴)
   - 축 결정: 해당 role의 표준 하이퍼큐브 정의(택사노미 def) 우선,
     코퍼스 실증 조합으로 보정
3. **서술문 주석**: 해당 role의 텍스트 블록 element(…Explanatory)로 단순 매핑 + 원문 첨부
4. 분반기 모드: role 세트 동일 — 단 후보 정렬 시 동업종 **분반기 인스턴스** 실증에 가중
   (세부 레벨 차이는 자동 반영됨: 분반기 실증엔 세부 항목이 애초에 적음)

**게이트 F-2**: 기공시사 DSD → 주석 role 배정 일치율 + 표 차원 매핑 일치율 측정
(1차 목표: role 배정 85%+, 표 매핑은 실측 후 기준 설정 — 최초 실행이 벤치마크)

## F-3. 승계 모드 (케이스 1: 자기 기말 인스턴스 보유)

1. 자기 기말 XBRL을 D-1/D-2 파서로 로드 → element 선택·확장 정의·role 구성 **그대로 승계**
2. D-3b 추천은 기말에 없던 신규 계정에만 작동 (판단 최소화)
3. 기간 체계만 분반기로 변환 (F-1의 3번)
4. D-4c 연동: 승계 전 신버전 택사노미 호환성 점검 (폐지 element 대체 후보)

**게이트 F-3**: 신원종합개발 — 기말 인스턴스(있다면) 또는 반기 실물과 왕복 대조.
없으면 코퍼스에서 기말+반기 모두 공시한 회사 1곳 선정해 "기말→반기 생성 vs 실제 반기" 대조

## 작업 순서·의존성

```
전제: D-3b 게이트 통과 (매핑 엔진 확정) — Phase F 전체의 기반
F-1 (본문, 하) → F-2 (주석, 상) → F-3 (승계, 중)
```
- F-2의 표→차원 매핑은 복잡 추론 — Claude Code **Opus 권장** 구간
- 검증은 전 단계 자동 (기공시사 = 공짜 정답지). 문용님 역할 = 최종 감리:
  게이트 통과 후 샘플 워크시트 1건을 실제 편집기에 전사해보며 사용성 확인
  ("검색어로 element가 실제로 찾아지는가"가 실전 게이트)

## 스코프 제외
- 편집기 자동 입력(RPA) — 후순위 목록 유지
- XBRL 인스턴스 파일 직접 생성 — 편집기가 유일한 공식 작성 경로 (DSD 창작 금지와 동일 원칙)
- K-GAAP 회사

# 게이트 보고 — [UI-7확장] 반영 화면 2차 수확 (2026-08-13, 델타 2026-08-04h)

## 구현

1. **금지어 확장(4면)**: HTTP 상태코드(4xx/5xx 단독 표기 — 소수
   표기 5.114·"400행" 수사와 구분하는 정규식)·"서버가 강제" 류
   시스템 문구를 금지어에 추가, GLOSSARY 동기화(UI-9분 소급 등재
   포함). 기존 "서버가 이 순서를 강제합니다" 문구는 자동 실행 도입과
   함께 화면에서 제거.
2. **점검 자동 실행**: 수정 확인 탭 진입 시 적용 전 점검이 자동
   실행 — 수동 실행 버튼 제거, 대기 화면은 "수정 내용을 점검하고
   있습니다…", 재실행은 [다시 비교]만.
3. **파일 메타 실명화**: SHA1 → **"원본 지문 (반영 후 무결성
   대조용)"**(헤더·메타 행) / 편집기 버전 표기를 UI-9 배지 체계로
   단일화 — 값 중복 제거, 검증된 편집기 배지에 버전 병기("검증된
   편집기 5.049") / &cr;-only 셀 → **"줄바꿈 표기만 있는 빈 셀"**
   (메타 행·점검 그룹·툴팁·이력 전면).
4. **반영 옵션 카드**: 해당 0건 옵션은 접힘 — 둘 다 0건이면 "자동
   보정 대상이 없습니다 — 값 수정만 반영됩니다" 한 줄, 문구 평문화
   ("빈 셀로 정리합니다", "추출 때 결정").
5. **3단 과업 흐름**: 수정 확인 화면 상단에 **[1. 수정한 엑셀] →
   [2. 바뀐 내용 N건 (자동 점검)] → [3. DSD에 반영]** 스트립.
   0건 = 주 버튼 비활성 + 안내 / N건 = "선택한 N건 DSD에 반영" /
   "원본은 그대로 둡니다" 상시 — UI-7 구축분 재배치.

# 게이트 보고 — [패치 A-7] 단위 인지 크로스 검증 (2026-08-05)

발원: 실전 검토 — 본문(원)↔주석(천원) 확인. A-6 미발견 사유② 68건이
직접 대상.

## 구현

1. **공용 단위 리졸버 `units.py` (단일 소스)**: 마커("(단위: 원/천원/
   백만원)" 변형 포함) 감지 → 배율 확정. **표별 상이 지원** —
   각 표(region) 직전 행들에서 마커 탐색, 없으면 시트 상단 폴백,
   그래도 없으면 **None(단위 미상) = 환산 보류, 자릿수 추정 금지**.
   V-1(태깅 검증)의 시트 단위 정규화(`_detect_unit`)와 같은 개념 확인
   → 정규식·배율 표를 이 모듈로 단일화(V-1은 재사용 + "미표기→원
   가정" 관례만 유지).
2. **크로스(주석대사) 적용**: 동일 단위 raw 비교(±2 관례) 우선 —
   불발 시에만 배율 확정 상이 쌍을 원 단위 환산 후 비교, **허용오차
   = 굵은 쪽 배율 미만**(천원 ±999·백만원 ±999,999). 판정
   **"일치(단위환산)" 분리 집계**(`note_found_conv`) — 기존 일치
   불변. 폴백(참조 없는 정보성 탐색)은 현행 raw 유지.
3. **검증내역 표기**: 유형 "크로스(단위환산)" | 내용에 배율
   좌×N/우×M·허용오차 | 좌·우 값 = **환산식 엑셀 수식**
   (`=셀×배율`) | 판정·차이 수식 — 셀 추적으로 증적 가능.
4. **총괄표**: N열 "크로스 일치(단위환산)" 별도 집계 (원형 5열
   불가침 — A-6 수행 열 뒤).
5. **사유 재분류**: 배율 확정 상이 쌍이 환산 후에도 미발견 →
   "③매칭 불가(단위환산 시도 후 미발견)". ② 라벨은 "천배 후보 —
   단위 마커 미상"으로 한정(미상 케이스 참고용 잔존).

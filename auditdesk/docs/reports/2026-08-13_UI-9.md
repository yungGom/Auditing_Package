# 게이트 보고 — [소품 UI-9] 편집기 버전 배지 상태 3분리 (2026-08-13)

현행 문제: 버전 부재와 미검증 버전이 "미검증 편집기 null" 하나로
표시 — 내부 표기 null 화면 누출.

## 구현

작업 파일 개요의 편집기 버전 배지를 상태별 분리 (레이블 "editver"도
"편집기 버전"으로):

| 상태 | 배지 |
|---|---|
| a. 버전 있음 + 검증 목록 등재 | 녹색 "✓ 검증된 편집기" (클릭 = 즉석 버전 확인 유지) |
| b. 버전 있음 + 미등재 | 황색 "편집기 버전 X.X — 아직 검증 목록에 없음. 무수정 반영 1회로 지문 일치 확인 시 등록됩니다" |
| c-1. 버전 없음 + 수신물 | 중립 "공시 수신물 — 열람용 (편집기 버전 정보 없음이 정상)" |
| c-2. 버전 없음 + 비수신물 | 황색 "버전 정보 없는 파일 — 반영 전 무결성 확인 권장" |

- **수신물 판정**: 추출 산출의 열람용 표식(소스 식별 자산 `viewonly`)
  을 세션 메타로 승계 — 추출 전에는 수신물 파일명 규약(접수번호
  14자리)으로 잠정 판정.
- 값 표시 폴백 "(없음)"→"(정보 없음)", **금지어에 null·undefined·
  None 추가** — 3면(화면·산출물·설명서·라우터) grep 확장.

## 구현

- **기본 최근 5건** + "전체 보기 (N건 · 회사별)" 접기/펼침 버튼.
- **펼침 시 회사별 그룹** — N-1 메타(`company`, 친화명 소급 포함)
  재사용, 그룹 헤더에 건수.
- **행 한 줄 압축**: 핀 아이콘 | 친화명 | 작업 상태 배지 | 시각 |
  핀·숨김 버튼 | 열기.
- **핀 고정**: 목록 맨 위 정렬, 서버 영속(세션 플래그 — 브라우저
  무관). **숨김**: 목록 제외만 — 헤더에 "숨김 N건 (원본 파일은
  보존)" 상시 명시 + [숨김 보기]에서 [숨김 해제]로 복원. 플래그
  전용 API 신설, 세션·원본 파일·작업 기록 무손실.
- **30일 자동 숨김 옵션 (기본 꺼짐)**: 체크박스 — 핀 제외, 표시
  계층에서만 적용(데이터 무변경).

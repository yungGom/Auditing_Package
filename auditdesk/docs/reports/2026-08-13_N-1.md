## 구현 — rcept_no 정체성 불변, 표시 계층만

- **캐시 규약 불변**: 수신물 파일·폴더명(`{corp_code}/{rcept_no}…`)은
  그대로. 수신 시 **사이드카 `{rcept_no}.name.json`**(회사명·보고서명·
  접수일)만 추가 기록.
- **표시 계층**: `friendly_name()` — `{회사명}_{보고서명}_{기간}`
  (기간은 보고서명 괄호에서 추출, 첨부 표식 유지, 파일명 안전 문자
  치환). 세션 메타 `display_name`으로 실려 홈 목록·작업 파일 헤더에
  표시 (UI-8이 이 메타 재사용).
- **기존 캐시 소급 (가능한 만큼)**: 사이드카 없으면 `corp_code`
  폴더명 → 로컬 회사코드 캐시로 **회사명만 소급**, 보고서명은
  오프라인 확인 불가라 접수번호 유지(`{회사명}_{접수번호}`). 소급도
  불가하면 기존 파일명 그대로 (거짓 명명 금지).
- **산출물 파일명 통일**: 본문 열람용 엑셀 산출이 친화명으로 생성
  (`조선내화_반기보고서_2025.06.xlsx`) — 합계검증 산출(AI_Footing)은
  이 엑셀명을 승계. [DSD 저장] 제안 파일명도 친화명.

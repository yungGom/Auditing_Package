## 1. 원인 확정 + 전수 목록 (지시 1항)

**재현 확보(통제 3호)**: 주석 표 첫 열 ROWSPAN 병합 + 하단합계
단수차를 심은 합성 픽스처로 동일 오류 재현 — 오류 메모 대상 R8C1이
병합 A6:A8의 **내부 좌표**라 openpyxl이 MergedCell(읽기 전용)을
돌려주고 `cell.comment = …`에서 AttributeError → AI_Footing 생성 전체
중단. 경위는 지시대로: B-6c 분할로 뭉텅이 문서의 주석 표(병합 다수)가
처음 오류 표시 대상에 진입 — 기존 픽스처는 해당 위치에 병합이 없어
게이트 미검출.

**조립 경로 셀 대입 전수 grep** (`.value/.comment/.fill/.font/
.hyperlink` 등 셀 속성 대입, 시험 코드 제외):

| 모듈 | 로드 방식 | 기입 대상 | 병합 유입 |
|---|---|---|---|
| foot_excel (AI_Footing·검증내역) | load_workbook | **추출 원본 시트**(오류 표시·복귀 링크·왕복 링크) + 신설 시트 | **위험 — 원인 지점** (comment 2·링크 2) |

## 2. 수정

- **`cellsafe.py` 신설(단일 소스)**: `anchor`(병합 내부 좌표 → 좌상단
  앵커) + `put`(value/comment/fill/font 안전 기입 — **기존 메모
  이어붙임, 덮어쓰기 금지** / 실패 시 예외 전파 대신 failures 목록
  축적).
- **foot_excel**: 위험 지점 4곳(푸팅·크로스 오류 표시, 총괄표 복귀
  링크, 검증내역 왕복 링크) 전부 헬퍼로 교체. **기입 불가 항목은
  검증내역 하단에 "기입 불가 N건 — 시트·좌표·사유"로 노출**하고
  생성은 계속(지시 3항 — 침묵 금지). 반환 dict에 `write_failures`.
- **guide_check**: 로드 후 점 기입 4곳 헬퍼 교체 + stats에
  `write_failures` (신설 시트라 구조상 병합 불가지만 규약 통일).
- **jobs**: 오류 배너 요지에서 예외 원문 노출 제거 — "작업 중 오류
  (예외형) — 상세는 작업 기록 오류 로그에 저장" (지시 4항. trace는
  종전대로 작업 기록에만 저장, 화면 배너는 detail만 표시함을 확인).

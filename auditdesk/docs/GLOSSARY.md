# AuditDesk 용어 사전 (GLOSSARY) — 화면·산출물·설명서 단일 기준

> 원칙 (UI-6): **코드 식별자·패치 ID는 불변** — 사용자에게 보이는
> 문자열만 교체한다. 패치 ID(V-1·A-5·F-3 …)와 영문 모듈명
> (Workbench·Studio·Explorer·Footing)은 화면·산출물·설명서에 노출
> 금지 (내부 로그·GATES.json·docs/ 스펙 문서는 허용 목록).
> 이 표가 3면(화면 UI · 산출물 엑셀 · USER_GUIDE)의 단일 기준이다.

## 영역·화면 이름

| 내부용어 | 화면용어 | 한 줄 정의 |
|---|---|---|
| DSD Workbench | **DSD 작업** | 감사보고서 DSD를 엑셀로 변환·수정·반영하는 영역 |
| XBRL Studio | **XBRL 작성 지원** | 태깅 추천·확정과 전사 가이드를 만드는 영역 |
| DART Explorer | **공시 조회(DART)** | 공개 공시·XBRL 자료를 검색·수신하는 영역 (수신 전용) |
| DSD·XBRL·DART TOOLKIT | **감사 공시 실무도구** | 앱 부제 |
| 세션 | **작업 파일** | DSD 1건에 대한 변환·검증 작업 단위 |
| Footing 탭 | **검증** 탭 | 제출 전 검증 3종(합계·전기·태깅)이 모인 탭 |
| 택사노미 체크 | **택소노미 버전 점검** | 신버전 택소노미와의 호환(폐지·대체) 점검 |
| 매핑 확정 | **계정 매핑 확정** | 계정과목↔태깅 요소 연결을 회계사가 확정하는 화면 |
| 작성 워크시트 | **전사 가이드 작성** | 편집기 입력용 가이드 엑셀을 만드는 화면 |
| 차원 표 뷰어 | **XBRL 표 뷰어** | 공시 XBRL을 표 형태로 보는 화면 |
| 트리 뷰 | **택소노미 계층 뷰** | 표준 계정 체계를 트리로 보는 화면 |
| XBRL 파이프라인 | **XBRL 수신** | 공시 XBRL 자료를 내려받아 엑셀로 푸는 화면 |
| 상태 (E-0) | **상태** | 도구 상태 요약 (뱃지 표기 없음) |

## 기능·동작

| 내부용어 | 화면용어 | 한 줄 정의 |
|---|---|---|
| extract(추출) | **엑셀 변환** | DSD → 편집용 엑셀 |
| repack(역변환) | **DSD 반영** | 수정 엑셀 → DSD (위치 기반 값 교체) |
| Footing 검증 (A-4/A-5a) | **합계 검증** | 재무제표 합계·주석 대사 검증 |
| 전기대사 (A-5b) | **전기와 일치합니까?** (진입) / 결과 화면·산출물은 **전기 대조** | 당기 보고서의 전기값 ↔ 전기 보고서 대조 |
| XBRL 대사 (V-1) | **태깅 검증** | DSD 본문 값 ↔ XBRL 제출파일 값 대조 (제출 직전) |
| 롤포워드 스캐폴드 (F-3b) | **당기 작성 준비표** | 전기 반기 범위 + 기말 태깅 + 전기값 미리 채움 |
| 승계 (F-3) | **승계 (기말 태깅 이어받기)** | 자기 기말 제출파일의 태깅을 그대로 잇기 |
| 신규 추천 (D-3b) | **공시 사례 추천** | 상장사 공시 사례 기반 태깅 후보 Top-4 |
| 코퍼스 | **공시 사례 데이터** | 상장사 XBRL 공시 전수 집계 |
| 인스턴스 | **XBRL 제출파일** | 회사가 제출한 XBRL 데이터 파일 |
| 패키지 | **XBRL 자료** | 수신한 XBRL 압축 해제 폴더 |
| 차원표 | **XBRL 표** | 행 요소×열 요소로 렌더한 공시 표 |
| 컨텍스트/문맥 | **보고기간·연결구분** | 값이 속한 기간과 연결/별도 구분 |
| element | **태깅 요소** (ID 병기는 허용) | 표준 계정 식별자 |

## 판정·표기 (산출물 공통)

| 내부용어 | 화면용어 | 한 줄 정의 |
|---|---|---|
| 값 상이 | 값 상이 | 대조 차이가 허용오차 초과 |
| 태깅 누락 | 태깅 누락 | 매핑은 있으나 제출파일에 당기 값 없음 |
| 매핑 없음 | 매핑 없음 | 확정·승계 기록 부재 — 판정 불가(별도 집계) |
| 인스턴스에만 있음 | **제출파일에만 있음** | DSD 본문에 대응 행 없음 |
| 미분류 | 미분류 | 재무제표 유사 제목인데 유형 판별 불가 (숨기지 않음) |
| 프리필 | **미리 채움** | 전기값 자동 기입 (출처 추적) |

## 금지어 (UI·산출물·설명서 노출 금지)

- 패치 ID 패턴: `A-1`…`H-1`, `UI-1`…`UI-6`, `V-1a`, `F-3b`, `D-2c` 등
  `[영문]-[숫자]` 전부
- 영문 모듈명: Workbench, Studio, Explorer, Footing, TOOLKIT,
  pipeline(파이프라인은 "수신"으로)
- 허용 목록(내부 문서): GATES.json, docs/ 스펙·지시서·대장, 코드
  주석·식별자, git 이력

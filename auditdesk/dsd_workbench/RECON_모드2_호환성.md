## 판정: ②-1 (공시원본 경로) 채택 — 단, 본문 한정. 주석은 수동 확인 목록화

| 검토 항목 | 실측 결과 | 전기대사 관점 판정 |
|---|---|---|
| 컨테이너 | OpenDART document.xml = ZIP{단일 XML}, meta.xml 없음 | `converters/document_wrap.py`로 contents.xml 래핑 후 extract 가능 |
| 본문(BS/PL/CE/CF) | FS 시트·매핑 정상 추출 (홈플러스 4종, 4,149셀) | **②-1로 본문 전체 대사 가능** ✅ |
| 주석 | 헤더 마크업 상이(무마크업/!B 혼재) → 41개 중 12개만 분할 | 주석 대사는 신뢰 불가 → **"수동 확인 필요" 목록으로 출력** (허위 자동화 금지) |
| ②-2 폴백 (XBRL 팩트) | B-3 인스턴스 확보 가능 (상장사) | 비상장·주석은 XBRL도 한계 — 본문 한정 보조 수단으로 유지 |

## 운영 절차 (경계 유지)

1. dart_explorer에서 전기 공시원본 수신·래핑:
   `python -m dart_explorer search "회사명" ...` → document.xml 수신(캐시)
   → `converters.document_wrap.extract_to_excel()` → 전기 편집용 xlsx 산출
2. dsd_workbench recon은 **그 캐시 파일 경로**를 입력받는다 (직접 네트워크 금지):
   `python -m dsd_tool recon 당기.dsd --prior <dart_explorer 산출 xlsx>`
3. 출력의 주석 섹션: ②-1 전기 파일은 주석 분할이 부정확하므로
   제목 미매칭·기간열 없는 표와 함께 "수동 확인 필요"로 집계된다.

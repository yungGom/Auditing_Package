# Reusable task contract

Copy this for work started outside GitHub Issues.

```text
Project / component:
Problem or requested outcome:
Business rule source and owner:
GitHub Issue number (source of truth):
Input examples (synthetic or public only):
Expected observable behavior, including unknown/unmatched/error cases:
Out of scope:
Acceptance criteria:
Protected artifacts affected (paths/symbols or none):
Data or offline boundary affected:
Required automated checks and manual gates:
Baseline or known exception that must remain visible:
Human decision needed:
```

An agent may refine implementation details, but it must ask the owner about an undefined accounting judgment before encoding it as a rule.

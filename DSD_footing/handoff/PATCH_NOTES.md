## 패치 #1 — `statements.STMT` 표제 접두 확장

**증상.** 본표 5개 전부 `stmt_type = None`.

```
'요약반기재무상태표'      fullmatch → 없음
'요약반기포괄손익계산서'  fullmatch → 없음
```

`(연결|별도)?재무상태표` 패턴이 `요약반기` 접두를 못 받는다. 조선내화에서 잡은 과적합
(`연결`/`별도` 접두)과 **같은 유형의 재발** — 그때 접두 어휘를 2개만 열어놨다.

붕괴 경로:
```
stmt_type = None
 ├─ APPLY.get(None, ()) = ()          → A3·A5 전량 미실행 (SKIP 0의 정체)
 ├─ tieout.collect: book/sce 빈 채 종료 → B 28건 전량 미검증
 └─ refmap.collect_main: st not in STMT_TAG → 본표 금액 0건 → C 성립/미성립 0
```
(주석 금액은 1,627건 정상 수집됐다. 격자 추출·값 파싱은 멀쩡했고 본표 판정만 깨졌다.)

**변경.**
```python
# before
STMT = [("BS", re.compile(r"(연결|별도)?재무상태표")), ...]

# after
_PFX = r"(?:요약|중간|반기|분기|연결|별도)*"
STMT = [("BS", re.compile(_PFX + r"재무상태표")), ...]
```

순서·개수를 고정하지 않는 반복 그룹. `요약반기재무상태표`·`반기연결현금흐름표`·`재무상태표`가
모두 통과하고, `요약반기포괄손익계산서`는 `포괄`이 접두 목록에 없어 IS로 오인되지 않는다.

## 패치 #2 — `foot_hier` 총계행 스택 정산 (#1과 반드시 한 묶음)

**#1만 적용하면 즉시 새 오탐이 뜬다.**

```
p6 A3 DIFF  II. 비 유 동 부 채  표시=11,790,572  계산=27,284,013
                                차이 +15,493,441 = 자본총계와 정확히 일치
```

`is_tot`(총계행)이 `continue`만 하고 스택을 닫지 않아, 다음 구간 항목이 직전 구간의
미정산 소계에 흡수된다.

**삼성에서는 우연히 가려져 있었다.** 자본 대분류의 열 배치가 회사마다 다르다:

| | 삼성 p10~11 | LGES p6 |
|---|---|---|
| `I. 자본금` | **합계열**(col 3) → depth 13 | **세부열**(col 2) → depth 3 |
| `II. 비유동부채` | 합계열 → depth 13 | 합계열 → depth 13 |
| 결과 | `13 <= 13` → pop 발생 (정상) | `3 <= 13` 아님 → pop 안 됨 (흡수) |

삼성은 설계가 옳아서가 아니라 depth가 같아 우연히 정산됐을 뿐이다. 조판 과적합의 새 사례.

**변경.**
```python
# before
for d, k, raw, vals, is_parent, is_tot, ri, colof in rows:
    if p not in vals or is_tot: continue
    while stack and stack[-1][0] <= d:
        ...pop & emit...

# after — pop 루프 3곳을 pop_to 헬퍼로 통합
def pop_to(stack, p, depth):
    while stack and (depth is None or stack[-1][0] <= depth):
        ...pop & emit...

for d, k, raw, vals, is_parent, is_tot, ri, colof in rows:
    if is_tot:
        pop_to(stack, p, None)      # 구간의 끝 — 전량 정산
        continue
    if p not in vals: continue
    pop_to(stack, p, d)
```

**침묵 탈락 점검 완료.** A3가 실제로 일하고 있다:
```
삼성 p10 BS : Ⅰ유동자산 Ⅱ비유동자산 Ⅰ유동부채 Ⅱ비유동부채 전부 OK / I.자본금 SKIP(자녀가 p11)
LGES p6 BS : Ⅰ·Ⅱ·Ⅰ·Ⅱ 4건 전부 OK (양 기간)
LGES p10 CF: 12건 OK / 4건 SKIP — 투자활동 유입·유출 소계까지 삼성보다 깊게 잡는다
```

## 패치 #3 — `tieout` 기간 축 2차원화 (침묵 오류 제거)

**가장 위험했던 항목.** A/B/C 지표를 하나도 안 움직이면서 값을 조용히 틀리게 한다.

`tieout.run`은 `p=0 → 당기`, `p=1 → 전기`를 위치로 가정했다. 연차는 맞지만 중간재무보고의
손익·포괄손익은 기간 축이 **(당/전) × (3개월/누적) 2차원**이다.

```
LGES 손익계산서 '법인세비용차감전순이익'
  당기: 구 =     4,559  (당반기 3개월)   →  신 = -287,443  (당반기 누적)
  전기: 구 =  -287,443  (당반기 누적!)   →  신 = -257,073  (전반기 누적)
```

**구 코드는 당반기 누적 손실을 '전기' 값으로 집고 있었다.** 어휘(#4)를 먼저 고쳤다면
그대로 조용히 틀린 OK/차이가 나왔을 상황이다.

**변경 1 — `statements.py`에 판정기 신설.**
```python
SIDE_CUR = re.compile(r"\(\s*당\s*\)|당\s*(?:기|반기|분기|회계연도)")
SIDE_PRV = re.compile(r"\(\s*전\s*\)|전\s*(?:기|반기|분기|회계연도)")
SPAN_3M  = re.compile(r"3\s*개\s*월|삼\s*개\s*월")
SPAN_CUM = re.compile(r"누\s*적")

def _fill_merged(row, start, ncol): ...   # 헤더 병합셀 전파
def period_axis(tb):  -> ({(side, span): periodIdx}, nper)
def pick_period(axis, nper, side): ...
```

**핵심은 병합셀 전파였다.** 실측해 보니 `(당)` 표시가 각 구간의 **첫 열에만** 있다:
```
LGES 손익계산서 hdr행0: [2]'제6(당)기 반기'  [3]''      [4]'제5(전)기 반기'  [5]''
                hdr행1: [2]'3개월'          [3]'누적'   [4]'3개월'          [5]'누적'
                        └ 전파 없이는 p1(누적)의 당/전을 알 수 없다
```
라벨열이 새어들지 않도록 **첫 숫자열부터만** 채운다.

**`pick_period`의 안전 규칙.**
```python
for span in ("누적", None):
    if (side, span) in axis: return axis[(side, span)]
if not axis and nper == 2:      # 헤더 판독 실패 + 연차 2기간 관행
    return 0 if side == "당" else 1
return None                     # 미매칭≠0 — 0/1로 추측하지 않는다
```
- **3개월 열은 절대 고르지 않는다.** 재무상태표(시점)·현금흐름표(누적)와 대사 대상이 아니다.
- 폴백 조건을 `not axis and nper == 2`로 좁혔다. 헤더를 못 읽은 **연차**는 기존대로 0/1,
  기간이 3개 이상인 **중간**보고는 폴백 자체가 버그이므로 미검증으로 보낸다.

**변경 2 — `tieout` 루프 교체.**
```python
# before
for p, tag in ((0, "당기"), (1, "전기")):
    g(book, "BS", "자산총계", p)
# after
for side, tag in (("당", "당기"), ("전", "전기")):
    g(book, axis, "BS", "자산총계", side)
```

## 패치 #4 — 계정 별칭 고정 템플릿 + 중간보고 시점 가드

**B 연계 0/28 → 18/28 OK, 차이 0건.**

### 4-a. 별칭 테이블 (`tieout.ALIAS`)

자동 추론 대신 명시 목록. 새 표기를 만나면 여기에만 추가한다.

| 조회 개념 | 별칭 (앞쪽 우선) |
|---|---|
| 당기순이익 | 당기/반기/분기/중간순이익, 당기/반기/분기순손실 |
| 총포괄손익 | 총포괄손익·이익·손실, 반기/분기 접두형, **~소계** |
| 기말의현금및현금성자산 | 기말(의)현금…, **당반기말현금…**, 당분기말현금… |
| 기초의현금및현금성자산 | 기초의현금…, **기초현금…**('의' 없음) |
| 주식발행초과금 | 주식발행초과금, **자본잉여금** |
| 이익잉여금 | 이익잉여금, **결손금**, 미처리결손금 |
| 기타자본항목 | 기타자본항목, **기타포괄손익누계액**, 기타자본구성요소 |
| 총계(자본변동표 열) | 총계, **합계** |
| 환율변동효과 | 현금및현금성자산의환율변동효과, 외화환산으로인한현금의변동 |

`g()`가 별칭을 순서대로 시도하고, 하나도 없으면 `None` → 미검증.

### 4-b. 자본변동표 시점 라벨 일반화

```python
# before — '당반기말'을 못 잡는다
SCE_END = re.compile(r"(당기말|전기말)\)?$")
# after
SCE_END = re.compile(r"[(（]?\s*(당|전)\s*(반기|분기)?\s*기?\s*말\s*[)）]?$")
SCE_BEG = re.compile(r"[(（]?\s*(당|전)\s*(반기|분기)?\s*기?\s*초\s*[)）]?$")
```
`cur`(당기/전기) 판정도 정규식 그룹에서 직접 뽑도록 바꿨다. 매치 시 `(반기|분기)` 그룹을
`sce_span[("END", cur)]`에 기록해 아래 가드에 쓴다.

### 4-c. 중간보고 시점 가드 (가짜 '차이' 방지)

중간재무보고에서 재무상태표의 '전기' 열은 **직전 연차말**이고, 자본변동표·현금흐름표의
'전기'는 **전년 동기간**이다. 교차 대사하면 시점이 어긋난다.

```
LGES: 자본변동표 전기말 = 2024.6.30 → 자본총계 16,352,562
      재무상태표 전기열 = 2024.12.31 → 자본총계 15,717,080
      → 그대로 비교하면 '차이' 634,518 (가짜 지적)
```

`interim`(IS/CI에 3개월·누적 축 존재)일 때 **B6(전기) 5건·B8(전기) 1건을 미검증으로 흘린다.**
사유는 항목명에 남긴다: `[중간보고: 전반기말 vs 전기말 — 시점 상이]`.

### 4-d. B7 대사 대상 교체

```python
# before: 자본변동표 BEG 당기 = 자본변동표 END 전기   ← 중간보고에서 시점 어긋남
# after : 자본변동표 BEG 당기 = BS 전기 자본총계       ← 연차·중간 모두 성립
```
삼성 값은 양쪽 다 236,396,657로 동일해 결과 불변. LGES는 15,717,080으로 새로 OK.

### 4-e. B10 환율변동효과 — 규칙 완화 대신 구조 판정

```
삼성 : 증가 10,927,866 = 영업+투자+재무+외화환산  → 외화환산이 '증가'에 포함
LGES : 증가  2,188,974 = 영업+투자+재무           → 환율효과는 별도 가산 행
       기말 = 기초 + 증가 + 환율효과(-7,939)
```
같은 공식을 쓰면 한쪽이 반드시 틀린다. **"안 맞으면 항을 더해본다"는 규칙 완화이므로 금지.**
대신 **행 순서**로 가른다 — 환율효과 행이 `증가` 뒤·`기말` 앞에 있으면 별도 가산 항목,
앞에 있으면 이미 `증가`의 구성요소다.

```python
sep = r_inc < r_fx < r_end          # order["CF"] 행 인덱스
extra = (fx or 0.0) if sep else 0.0
add("B10", s_+"CF 증감 = 기말 − 기초" + (" − 환율변동효과" if sep else ""),
    inc, b_end - b_beg - extra)
```
`sep=False`면 항목명·값 모두 기존과 동일 → **삼성 B 시트 텍스트 무변화.**

이를 위해 `collect`가 `order[st][key] = 행인덱스`를 함께 반환한다.

## 남은 과제 (착수 안 함)

우선순위 순. **5번은 판정 규칙 변경이라 회계사 승인 사항.**

| # | 대상 | 효과 | 삼성 회귀 위험 |
|---|---|---|---|
| 5 | 이중 합계열 가로합 — `tcols` 2개 이상일 때 각 tcol의 성분 범위를 앞 tcol 이후로 한정 | LGES A DIFF **−58** | **중** (삼성 A2 OK 115건) |
| 6 | 셀 내 2줄 금액 파싱 (`'678,200\n(USD 500,000)'`) + 단일 NUM 금액열 → SKIP | LGES A DIFF −4, 침묵 과소계상 제거 | 하 |
| 7 | 롤포워드 표의 마지막 `합 계` 행(기말−유동항목) 세로합 제외 | LGES A DIFF −6 | 하 |
| 8 | `prose` F4 각주마커·불릿 예외 | LGES F4 35→소수 | 하 (삼성 F4=4 유지 확인) |
| 9 | **A5 어휘 별칭** — `A5_RULES` 항목을 별칭 튜플로. 미착수(별도 패치로 분리) | LGES A5 6→다수 | **중** (삼성 A5 OK 18건, A_total 변동 가능) |
| 10 | BS 자본섹션 A1/A3 역할 분담 재정의 | LGES A DIFF −2 | **높음** — 회계사 승인 필요 |

**10번 상세.** LGES 재무상태표의 자본총계는 A3 후보로 생성되지 않는다(부채총계에서 스택을
닫은 뒤 자본 항목이 빈 스택을 만나 누적되지 않음). 그 자리를 A1이 메우는데 A1은 열별 독립
계산이라 오탐을 낸다. 지면에 X는 찍히지만 **틀린 X**다. 완전 침묵은 아니라 원칙 위반은
아니지만, A1이 '합계 별도열' 구조에서 열별 독립 세로합을 하는 게 맞는지부터 정해야 한다.

**9번 주의.** A5에 별칭을 넣으면 삼성에서 **새 규칙이 추가로 발화해 `A_total`이 늘 수 있다.**
지표 개선이라도 게이트는 불일치로 잡는다. 삼성 A5 증분을 먼저 측정하고 시드를 갱신할지
회계사와 정한 뒤 진행할 것.

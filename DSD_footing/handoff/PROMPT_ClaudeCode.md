# Claude Code 붙여넣기용 프롬프트

아래 블록 전체를 복사해 Claude Code에 붙여넣으면 된다.
그 전에 `handoff/` 폴더를 저장소 안(예: `_handoff/`)에 통째로 복사해 둘 것.

---

```
DSD Footing 자동화 도구 작업이다. claude.ai 세션에서 반기검토보고서(중간재무보고) 교차검증을
하고 패치 4건을 만들어 왔다. 삼성 회귀는 이미 통과시켰다. 저장소에 반영해 달라.

## 먼저 읽을 파일 (순서대로)

1. CLAUDE.md                        — 기존 인수인계 문서
2. _handoff/PATCH_NOTES.md          — 이번 패치 4건의 증상·원인·변경 내용·검증 결과 (핵심)
3. _handoff/GATES_seed.json         — 삼성/LGES 두 샘플의 회귀 기준선
4. _handoff/patch_statements.diff   — statements.py 변경 (2곳)
5. _handoff/patch_tieout.diff       — tieout.py 변경 (3곳)
6. _handoff/statements.py           — 패치 적용된 전체 파일 (참고용)
7. _handoff/tieout.py               — 패치 적용된 전체 파일 (참고용)
8. _handoff/gate.py                 — 회귀 게이트 하네스 (final.py 출력 파서)

## 절대 하지 말 것

- **_handoff/*.py 를 저장소 파일에 덮어쓰지 말 것.** 저장소에는 소계 중복계상 3경로 수정이
  들어 있고 claude.ai 사본에는 없다. 덮어쓰면 그게 날아간다.
  diff 2개를 보고 **변경 지점만 골라 얹어라.** statements.py 2곳, tieout.py 3곳뿐이다.
- 판정 규칙을 완화하지 말 것. "안 맞으면 항을 하나 더해본다" 류 금지.
- 외부 API·네트워크 코드 금지. 완전 오프라인 유지.
- 실제 클라이언트 수치를 저장소에 넣지 말 것. 검증 샘플은 DART 공개본만.

## 해야 할 일

### 1단계 — 병합
patch_statements.diff / patch_tieout.diff 의 변경을 저장소 현재 파일에 적용한다.
충돌 가능 지점은 `foot_hier`(저장소 소계 수정과 같은 함수일 수 있음)와 `check_table` 주변이다.
충돌하면 **멈추고 보고**할 것. 임의로 합치지 말 것.

### 2단계 — 회귀 확인 (필수)
삼성 샘플로 `run_gates.py`(또는 _handoff/gate.py)를 돌려 GATES_seed.json의
"삼성전자_FY25_별도" 23개 지표와 대조한다.

**지표가 하나라도 어긋나면 즉시 멈추고 보고.** 코드를 더 고치지 말 것.

집계만 보지 말고 예외 색인(xlsx) 7개 시트를 **행 단위로** 대조할 것.
claude.ai 세션에서는 패치 4건 적용 후에도 7개 시트가 텍스트까지 완전히 동일했다.
저장소 버전은 소계 수정이 더 들어 있으므로 A_예외색인 행 수가 다를 수 있다 —
그 경우 seed의 A_* 값을 저장소 실측으로 갱신하고, **B/C/F/D는 반드시 동일해야 한다.**

### 3단계 — LGES 축 추가
LG에너지솔루션 반기검토보고서(DART 공개본)로 돌려 GATES_seed.json의
"LG에너지솔루션_FY25_반기검토" 값과 대조하고, GATES.json에 세 번째 회귀 축으로 등록한다.
B는 OK 18 / 차이 0 / 미검증 10이어야 하고, **미검증 10건은 전부 사유가 명시돼 있다**
(seed의 _B미검증_10건_전부_정당 참조). 차이가 1건이라도 나오면 보고.

### 4단계 — 문서 정정
CLAUDE.md의 소계 중복계상 위치 `p71(4)` → `p72(4)`로 고친다.
본문 예시 "예: p71 이자수익 아래 상각후원가 금융자산에 대한 이자수익 230,516"도 p72로.
(p71은 23.기타수익 및 기타비용이라 230,516이 없다. p72가 24.금융수익 및 금융비용이다.)

### 5단계 — 커밋
Conventional Commits로 패치 단위로 나눠 커밋한다. #1과 #2는 **반드시 한 커밋**으로 묶어라
(#1 단독 적용 시 A3 오탐 2건이 새로 생긴다).

  fix(statements): 중간재무보고 표제 접두 인식 + foot_hier 총계행 스택 정산
  fix(tieout): 기간 축을 (당/전)×(3개월/누적) 2차원으로 해석
  feat(tieout): 계정 별칭 템플릿 + 중간보고 시점 가드
  docs: 소계 중복계상 위치 p71→p72 정정, LGES 회귀 축 추가
```

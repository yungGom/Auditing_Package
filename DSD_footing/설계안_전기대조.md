# 설계안 — 전기 보고서 대조 (`--prior`) · 구현 금지, 승인 대기

> 상태: **설계안만. 착수 여부는 회계사 결정.** (2026-08-13)
> 원 요청("DART 공시로 완전성 보완")은 절대 제약(완전 오프라인·외부 API 금지) 위반이라
> 우회 설계로 대체한다. 감사 중 도구가 회사 공시를 자동 조회하면 접근 로그가 남아
> 실무상으로도 위험하다.

## 입력 방식 — 오프라인 우회

회계사가 DART에서 전기 감사보고서를 **수동 다운로드**해 로컬에 두고, 도구는 그 파일만 읽는다.

```
python foot.py 당기보고서.pdf --prior 전기보고서.pdf
```

`--prior` 미지정 시 현행 동작 그대로 (4축 게이트 무변화 원칙).

**`--prior`를 단일 파일로 가정하지 않는다.** 당기가 분기·반기 검토보고서면 대사 상대가
여럿이다(전분기 누적 검증에는 전분기 검토보고서가, 기초 잔액 검증에는 전기 연차
감사보고서가 각각 필요 — 아래 '입력 문서 조합' 참조). 두 갈래를 구분해 받는다:

```
--prior-annual   전기 연차 감사보고서 (기초 잔액·주석 완전성 대사용)
--prior-interim  전기 동기간 분기·반기 검토보고서 (누적 실적 대사용)
```
같은 문서를 양쪽에 겸용할 수는 없다(연차 보고서에는 3개월·9개월 누적 열이 없다).
조합별로 무엇이 검증 가능해지는지는 '입력 문서 조합' 절에 표로 정리한다.

## 검증 항목 (우선순위 순)

### P1. 전기말 잔액 대사 — 가장 값이 큼
**B7(자본변동표 기초 = 전기말 자본총계)·B9(CF 기초현금 = 전기말 현금)가 4축 전부
미검증인 이유가 '설계상 전전기 필요'였다.** 전기 보고서가 들어오면:
- 당기 보고서의 '전기' 열 ↔ **전기 보고서의 '당기' 열** 대사 (⚠ 아래 시점 가드)
- B7·B9의 '전기' 측이 전기 보고서의 전전기… 아니라 전기 보고서 당기 열로 해소
- 본표 전 항목으로 확장 가능: 당기 BS 전기열 전체 ↔ 전기 BS 당기열 전체
  (AuditDesk '전기대사'와 같은 개념 — 여기서는 표시 수치끼리, PDF 기반)

### P2. 주석 항목 누락 플래그
전기 보고서의 주석 선언 목록(`notes.run`)과 당기 목록을 대조 — 전기에 있던 주석
제목이 당기에 없으면 '주석 누락 후보' 플래그 (오류 아님, 확인 대상 표시).

### P3. 표현 일관성 — 전기 표현을 기준으로
전기 보고서에서 F2 그룹별 사용 표현을 추출해 **`--terms` 기준으로 자동 사용**.
명시적 `--terms` 파일이 있으면 파일이 우선.

### P4. 계정과목 명칭 변경 감지
본표 라벨(key 정규화 후)을 전기·당기 비교 — 전기에만 있는 라벨 + 당기에만 있는
라벨 쌍에서 값이 일치하는 조합은 '명칭 변경 후보'로 표시.

## ⚠ 시점 가드 (필수 선행 설계)

전기 보고서의 '당기' 열 ↔ 당기 보고서의 '전기' 열 대사가 기본 구조인데,
**중간재무보고면 시점이 어긋난다**:
- 당기 반기보고서의 BS '전기' 열 = 직전 연차말 → 전기 **연차** 보고서와 대사 가능
- 그러나 IS/CI '전기' 열 = 전년 동기간 → 전기 연차 보고서와 대사 불가
- 기존 `tieout`의 interim 가드(전반기말 vs 전기말 시점 상이 → 미검증)와 같은 논리를
  문서 조합별로 정의해야 한다 — 조합 목록은 바로 아래 '입력 문서 조합' 절.
- 판정 불가 조합은 **미검증으로 낸다** (가짜 차이 금지 — B10 안전장치와 같은 원칙).

## 입력 문서 조합

당기 보고서 종류에 따라 대사 상대 문서가 다르고, 문서가 갖춰지는 만큼만 B1~B10이
새로 검증 가능해진다. 부족한 조합은 해당 항목만 미검증으로 남긴다(추측 금지).

| 조합 | 대사 가능 시점 | 새로 검증되는 항목 | 여전히 미검증 |
|---|---|---|---|
| 당기 연차 + 전기 연차 | 당기 BS 전기열 = 전기 BS 당기열 (동일 시점) | **B7**(SCE 기초총계=전기말 자본), **B9**(CF 기초현금=전기말 현금) — 4축 전부 막혀있던 항목. 본표 전 항목 전기열 완전성 대사 | 없음(이 조합이 완전) |
| 당기 반기 + 전기 연차 | 당기 BS 전기열(=직전 연차말) = 전기 BS 당기열 | **B7·B9**(BS 시점이라 성립), 자본변동표 기초 총계 계열(B6류 중 BEG) | SCE·CF의 IS/CI 계열 '전기' 비교(전년 동기간 필요 — 이 조합엔 없음). 기존 interim 가드가 이미 이 부분을 미검증으로 흘리고 있어 그대로 유지 |
| 당기 반기 + 전반기 검토 + 전기 연차 | 반기: 당기 반기 누적 열 = 전반기 검토보고서 당기 누적 열 (동일 시점, 전년 동기간). 연차: 위 행과 동일 | **B2·B4·B5**의 '전기' 측(IS/CI 당기순이익 등, 지금은 중간보고 가드로 미검증 처리되던 것이 전반기 검토보고서가 있으면 해소), + 위 행의 B7·B9 | 전전기가 필요한 항목(B7·B9의 '전기' 측 자체는 이미 위에서 해소되므로 없음) |
| 당기 분기 + 전분기 검토 + 전기 연차 | 분기: 당기 분기 누적 열 = 전분기 검토보고서 당기 누적 열. 연차: 위와 동일 | 반기 조합과 동일한 항목이 분기 단위로 성립 | 동일 |

**공통 원칙:** 각 조합에서 '당기 보고서 열'과 '대사 상대 보고서 열'의 시점이 정확히
같은 라벨(같은 side·같은 span)일 때만 대사한다 — `statements.period_axis`/`pick_period`의
축 해석을 대사 상대 문서에도 그대로 적용해 재사용한다. 새 판정 로직을 만들지 않는다.

## 산출물

- 예외색인에 `P_전기대사` 시트 신설: 항목·전기 보고서 값·당기 보고서 전기열 값·판정
- 게이트: `--prior` 지정 실행은 별도 지표(P_*)로, 기존 24지표와 분리
  (미지정 실행의 24지표는 불변이어야 한다)

## 착수 시 확인 사항

- **단위 상이는 이미 해결된 문제다.** 휴맥스(본표 원/주석 천원)로 표 귀속 단위 + 환산
  로직이 이미 구현·검증되어 있으므로(`refmap.table_units`) 그대로 재사용하면 된다.
  ⚠ 다만 **환산 허용오차(거친 단위의 1스텝)가 두 문서에 걸쳐 이중으로 적용되지
  않도록 주의**할 것 — 당기·전기 각각 단위가 다르고 대사 시 원 환산까지 하면
  스텝이 두 번(당기 표시→원 환산 1회 + 전기 표시→원 환산 1회) 쌓일 수 있다.
  대사 tol은 원 환산 후 단 한 번, 두 값 중 더 거친 쪽 단위 기준으로 산정한다
  (기존 `refmap._pair_tol` 로직과 동일한 원칙 — 새로 설계하지 말고 그 함수를 확장).
